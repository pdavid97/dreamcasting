# 드림캐스팅 광장

웹소설 실사화, 옛 드라마 리메이크, 한국판과 할리우드판 리메이크의 가상 캐스팅을 제안하고, 토론하고, 투표하는 비상업 팬 커뮤니티 프로토타입입니다.

- 공개 주소: https://pdavid97.github.io/dreamcasting/
- 배포: `main` 브랜치에 올리면 GitHub Pages가 자동으로 반영합니다.
- 현재 단계: 단일 페이지(index.html). 투표와 게시글은 각자의 브라우저에 저장되며, 함께 활동하는 참가자는 예시 봇입니다.

## 이미지

배우 프로필 사진과 작품 포스터는 TMDB API로 불러옵니다.

This product uses the TMDB API but is not endorsed or certified by TMDB.

## 고지

후보 배우 목록은 토론을 시작하기 위한 예시이며 실제 리메이크 계획이나 섭외와 관계가 없습니다. 작품명과 인물명은 각 권리자의 것입니다.
