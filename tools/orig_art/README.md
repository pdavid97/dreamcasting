# 원작 대표 이미지 (topics.work.oart)

리포트의 원작 패널과 포스터 하이라이트에 쓰는 이미지. 사람이 고르지 않고 자동으로 정한다.

1. 필요한 얼굴 수 = 원작 배역 수와, 원작 배우의 크레딧 순번 중 큰 값 (예: 더 글로리는 송혜교 1번, 임지연 3번이라 3명)
2. TMDB 포스터와 스틸에서 얼굴 위치만 찾고(YuNet, 신뢰도 0.85), 필요한 수 이상이 비슷한 크기로 한 줄에 모인 이미지를 단체 사진으로 본다
3. 위아래로 흩어진 콜라주와 몽타주, 너무 작은 얼굴은 제외
4. 해당하는 이미지가 없으면 원작 포스터 (kind=poster)

얼굴이 누구인지는 판별하지 않는다. 실행: `python3 tools/orig_art/pick.py topics.json` 후 결과를 topics.work.oart 에 넣는다.
