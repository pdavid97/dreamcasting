## 3. 화면 검수 순서 (약 15분)

1. 공개 주소 접속, 리메이크 2.0 > 내 이름은 김삼순: 작품 정보 펼치기, 지표(TMDB 평점, 화제성), 감상하러 가기(예고편 재생, 웨이브/왓챠 버튼)
2. 배역 보드에서 후보 이름 클릭 > 배우 페이지: 사진, 만 나이, 필모, 물망 작품, 팬 게시판
3. 배우 페이지 필모에서 연기 점수 주기(로그인 필요) > 오른쪽 올해의 배우 메타 지수 반영 확인
4. 캐스팅 시트: 배역마다 후보 선택, 한 배역은 직접 적기, 한 배역은 연도 선택(예: 2008년의 배우) > 게시 > 시트 카드에 "(2008년)"과 당시 나이 표시
5. 시트 카드 포스터 > 이미지 올리기(내 시트만), 다른 사람 포스터 신고
6. 새 주제 제안(300P 필요): 리메이크 2.0 + "커피프린스 1호점" 입력 > 원작 출연진 자동 채움 / 크로스 미디어 + 게임 > 장르, 개발사, 플랫폼 기본 항목
7. 우상단 내 페이지 > 취향 등록 > 알림
8. 휴대폰으로 같은 주소 열어 레이아웃 확인

## 4. 알려진 한계

- 배우 수상 기록은 Wikidata 등록분만 보여 줘서 한국 배우는 비어 있는 경우가 많아요. 보완안: 출처 링크가 있는 유저 제보(케미 제보와 같은 방식) 추가
- TV 시청률(닐슨 등)은 공개 API가 없어 제보와 승인 방식이에요
- 국내 시청처 버튼은 플랫폼 작품 페이지가 아니라 TMDB 시청처 페이지로 연결돼요(직링크는 제휴 후 노출 자리로 등록)
- 웹툰, 소설 원작은 TMDB에 없어 작품 정보 대신 주제 링크(연재처)를 붙이는 방식이에요
- metrics 함수는 누구나 호출할 수 있지만 20시간에 한 번만 실제로 돌아요
