# 배역 키워드 매칭 방법론 (검토안)

목표: 배역과 원작 배우에서 키워드를 뽑고, 같은 키워드를 가진 후보를 찾는다. 키워드가 곧 선발 이유와 소개 문구가 된다.

## 1. 키워드 종류와 출처

| 묶음 | 예시 키워드 | 배역(원작 배우) 쪽 출처 | 후보 쪽 출처 |
|---|---|---|---|
| 나이대 | 20대 초반, 30대 중반 | 원작 배우가 그 역을 맡았을 때 나이(생일, 방영 연도) | 지금 나이 |
| 인지도 | 주연급, 라이징, 신인 | 원작 방영 당시 원작 배우의 위치(그 전 주연작 수) | TMDB 인기 지수 구간, 주연작 수 |
| 배역 유형 | 재벌, 기사, 형사, 저승사자, 아이돌 | 배역 이름과 설명, 작품 TMDB 키워드 | 출연작 배역명(같은 사전으로 분류) |
| 장르 | 로맨틱코미디, 판타지, 범죄 | 작품 장르, 작품 TMDB 키워드 | 출연작 장르 편수 |
| 이야기 소재 | 계약연애, 복수, 타임슬립, 학원물 | 작품 TMDB 키워드(영문)를 한글 사전으로 변환 | 주연(크레딧 3번째까지) 출연작의 TMDB 키워드 |
| 이미지 | 직진남, 츤데레, 차도남 | 운영자 또는 유저 태그(배역당 3개까지) | 유저 태그 누적, 위 소재와 배역 유형에서 규칙으로 추론 |
| 관계 | 상대역 케미, 원작 배우와 인연 | 상대 배역 1순위 후보, 원작 배우 필모 | 공동 출연작(이미 계산 중) |

원작 배우 쪽은 두 가지를 합친다.
- 그 배역 자체의 키워드(작품과 배역 설명)
- 원작 배우가 그 역을 맡기 전후 3년 출연작에서 자주 나온 키워드(배우의 그때 결)

## 2. 점수 계산

1. 키워드마다 가중치를 둔다. 흔한 키워드(예: 드라마)는 낮게, 드문 키워드(예: 저승사자)는 높게 잡는다(TF-IDF 방식, 후보 풀 전체 기준).
2. 배역 벡터와 후보 벡터의 코사인 유사도를 낸다. 묶음별로 따로 내서 합친다.
   - 정석 점수 = 배역 유형 0.30 + 소재 0.20 + 장르 0.15 + 나이대 0.20 + 인지도 0.15
3. 겹친 키워드 상위 2~3개를 그대로 소개 문구에 쓴다.
   - 예: "재벌 후계자, 계약연애, 로맨틱코미디. 원작 키워드 3개를 이미 다 해본 사람이에요."
4. 6명 칸 구성은 그대로 두고, 정석 3칸의 순위만 이 점수로 바꾼다. 화제, 케미, 와일드카드 칸에도 키워드 일치를 보조 점수로 더한다.

## 3. 데이터 확보와 비용

- 작품 키워드: TMDB `/tv/{id}/keywords`, `/movie/{id}/keywords`. 작품당 1회 호출, `work_keywords` 표에 영구 캐시.
- 후보 키워드: 후보 풀 배우 약 1,700명의 주연작 상위 15편. 작품 중복이 많아 실제 호출은 수천 회 수준. 주간 작업으로 나눠 채운다(하루 수백 회, TMDB 한도 안).
- 한글 변환: TMDB 키워드는 영문이다. 자주 나오는 300개를 한글 사전으로 만들어 두고, 사전에 없는 키워드는 점수에는 쓰되 화면에는 보이지 않게 한다.
- 이미지 키워드(츤데레 등)는 데이터 출처가 없다. 운영자 초기 입력과 유저 태그로 시작한다.

## 4. 학습(데이터 플라이휠)

- 표를 받은 후보가 가진 키워드는 그 배역에서 가중치를 올린다. 건너뛴 후보의 키워드는 조금 내린다.
- 배역마다 "유저가 실제로 원한 키워드"가 쌓이면 다음 주 재선발에 반영한다.
- 개인 취향에도 같은 키워드를 쓴다. 예: "이 유저는 재벌, 복수 키워드 배우를 자주 고름" → 첫 화면 작품 추천에 반영.

## 5. 한계와 주의

- TMDB 키워드는 해외 작품은 풍부하지만 한국 작품은 비어 있는 경우가 있다. 이때는 배역 사전과 장르로 보완한다.
- 배역명이 고유명사(예: 김신)인 경우가 많아 배역 유형은 배역 설명과 작품 키워드에 기대야 한다. 배역 설명이 짧은 배역은 운영자가 키워드를 2~3개 넣어 주는 편이 정확하다.
- 실존 인물에 대한 성격 단정은 하지 않는다. 이미지 키워드는 "배역 이미지"로만 쓰고 배우 본인 평가로 쓰지 않는다.

## 6. 진행 순서 제안

1. `work_keywords` 표와 수집 함수, 한글 키워드 사전 300개
2. 배역 키워드 추출(작품 키워드, 배역 사전, 원작 배우 전후 3년 출연작)
3. 후보 키워드 벡터 계산(주간 작업으로 채움)
4. recommend 정석 점수 교체, 소개 문구에 겹친 키워드 노출
5. 투표 결과로 키워드 가중치 학습
